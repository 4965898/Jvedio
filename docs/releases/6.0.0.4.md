# Jvedio 6.0.0.4（Jvedio30.5）/ Connector 0.3.5

本版只更新插件，桌面端无功能变化（仅随版本构建）。

## 更新内容

- **勾选保持**：JavDB 榜单与瀑布流（JAV-JHS 等脚本自动翻页）滚动加载时，已勾选不再丢失。滚动翻页、脚本弹窗与预览、地址栏变化都保留选择，可跨页累计挑选；手动翻页或刷新网页才开始新一轮挑选。
- **勾选响应**：修复滚动加载后在卡片上点击“＋Jvedio”提示“勾选失败，请重试”的问题（Chromium 内核浏览器，如 360 极速浏览器 X）。
- **番号识别**：新增 MKBD-S03、S2MBD-050、T28-611、N0659 等真实格式；日期与无意义字符仍被拒收。
- **按钮位置**：无日期行的榜单卡片，“＋Jvedio”改挂到“X分，由N人評價”评分行旁，长标题不再遮挡按钮；普通列表卡片仍在日期旁。
