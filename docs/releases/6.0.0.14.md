# Jvedio 6.0.0.14（Jvedio30.9）

本版为桌面端功能迭代与并发稳定性版本，**Connector 无变化（沿用 0.4.0），只需更新桌面端**。

## 新功能

- **演员筛选器**：演员界面新增侧栏筛选器（工具栏漏斗按钮开关），支持多属性联合筛选——面板之间为「与」条件、面板内多选为「或」条件：
  - 性别（全部/女/男/未知）、评分（双滑块）、爱好（关键词包含匹配，多词任一命中）；
  - 头像（有头像/无头像，按本地头像目录实时判断，刚下载完立刻可筛）；
  - 作品数量（0/1~5/6~10/11~20/21~50/>50，按当前影片库计数走聚合过滤）；
  - 年龄、出生年代、身高、体重、胸围、腰围、臀围、鞋码（数值档位多选，与统计图分桶语义一致）；
  - 罩杯、国家、民族（从库内实际值动态生成，含「未知」项）、血型（A/B/O/AB/未知）。
  - 底部「应用/重置」，应用后回到第一页；与统计窗口图表点击跳转的筛选条件可叠加。
- **演员右键「下载头像」**：从 Gfriends 头像库按演员名取图，功能与演员详情页「下载」按钮一致——显式操作视为刷新、覆盖已有头像，下载后当前页卡片即时刷新；选择语义与「同步信息」相同：编辑模式勾选多位即批量下载（请求间隔 500ms 防风控），否则为右键的这一位；完成后提示成功/未收录/失败数量，主日志逐条留痕；未启用 Gfriends 会有明确提示。
- **「演员资料补齐并发数」设置**：选项 → 扫描区新增输入框（1~5），默认 1（串行，防风控）；改动后下一次批量/手动补齐立即生效。并发越高越容易触发 JAVDatabase 的站点限速（404 过多），请酌情调整。

## 演员资料补齐成功率优化

- **候选番号按发行日期新→旧排序**并放宽到 15 个：JAVDatabase 收录偏新片，旧片更容易站内缺失；
- **番号清洗去重**：NFKC 归一、连字符统一、去多分片后缀（-CD1/-C2/-PART1/-DISC2）、FC2 归一，变体番号不再占用候选名额或产生无效 404；
- **站点限速拦截页检测**：请求命中「Your access to this site has been limited」（404 过多触发的 Wordfence 临时拦截）时，立即止损当前演员并明确提示「站点临时限速…稍后自动恢复」，不再盲目重试把拦截期越拉越长；
- **失败原因分类汇总**：任务失败信息按 站内缺失(404)/请求失败/无演员区块 分列，请求失败会提示检查 Cookie/代理；
- **无演员区块降级解析**：详情页 200 但没有演员区块时，全页搜索偶像链接（≤3 个）并按名字精确消歧，救回区块标签变体/站点改版场景；
- **按名字站内搜索兜底**：全部候选番号失败时按演员名（日文优先、罗马字兜底）站内搜索资料页，同样精确消歧防误配。

## 并发刮削根因修复

- **修复并发批量刮削「成功但没有演员/类别/导演」**：根因是 ORM 查询条件的静态字典在并发任务间互相覆盖，导致影片拿到别的影片的 JavDB 页码、抓错页面。刮削链所有相关查询改为直连 SQL，并在首次刮削时自动清理被污染的页码缓存（下次刮削重新搜索生成正确映射）；
- **页码校验防线**：JavDB 详情页标题不含当前番号时拒绝解析（可能是站点限频弹跳或页码缓存错误），防止把别的影片的字段挂到本片上；
- **修复同一插件多行源复用实例导致的「已添加了具有相同键的项」异常**：该异常此前会直接打断整个刮削任务，现降级为「该源失败，换下一个源」，完整堆栈进主日志；
- **JavDB 搜索匹配修复**：逐条目精确匹配番号，修复「精确匹配不在搜索结果首位就永远搜不到」的老问题。
