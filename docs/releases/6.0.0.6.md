# Jvedio 6.0.0.6（Jvedio30.7）

本版为桌面端功能迭代版本，**Connector 无变化（沿用 0.4.0），只需更新桌面端**。

## 新功能

- **演员搜索支持英文名**：演员页搜索框输入日文名或英文名（罗马字）均可命中，部分输入与大小写不敏感；导出「整个库/仅本页」与列表同口径。
- **Gfriends 头像库**：影片刮削、演员资料补齐需要下载头像时优先从 Gfriends 取图（按演员名索引、量大质高）；已有本地头像的演员不覆盖；查无此人或下载失败自动回退站点头像；索引本地缓存 7 天；设置「扫描与导入」中可关闭。
- **重复演员合并**：演员右键「合并到另一位」，影片关联合并到目标（自动去重），目标空缺的资料/评分/头像取自被合并者且不覆盖已填，被合并条目随后删除；支持多选模式批量合并同名重复演员；合并对话框候选按作品数排序、支持英文名搜索、同名重复自动预填。
- **字幕下载**：按番号从 SubtitleCat 查找字幕，语言偏好可自定义（默认简体优先、繁体兜底，可选 en/ja/ko 等）；保存位置可选影片目录（同名 .srt，「有字幕」筛选即时生效）或指定文件夹（番号.语言.srt，同番号共享）；支持刮削完成后自动下载；影片右键「下载字幕」（单选/多选批量）；任务页可看进度、取消、重启失败。
- **观看时长统计**：统计仪表盘概览新增「累计观看时长」；播放次数自本版起正常累计（此前版本无自增逻辑，历史播放不可追溯）。

## 优化

- 字幕文件夹、本地备份目录、NFO 导出输出目录、备份恢复的文件夹选择全部升级为现代对话框（地址栏可粘贴路径、收藏夹直达、可新建文件夹）。
- 影片右键「下载字幕」位于「在线观看」与「修改信息」之间，支持多选批量。

## 说明

- 首次使用 Gfriends 头像会下载约 6MB 索引并缓存 7 天。
- 字幕任务串行限速执行，批量下载会排队（防站点风控）。
- 下载地址：完整 ZIP / 同版 EXE（GitHub Release 资产）；升级源已同步。
