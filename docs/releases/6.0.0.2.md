# Jvedio 6.0.0.2（Jvedio30.3）/ Connector 0.3.0

本版新增**清单标签导入**：JavDB 等站点用户分享的影片清单，现在可以在保存时作为清单长期保存在「我的标签」中，随时调出。桌面接收端支持标签目录自动创建（`labelImportVersion 3`），筛选器标记的严格校验与既有行为不变。

## 清单标签：把影片清单保存为可调出的集合

- **插件新增「添加标签」多选下拉框**：位于小窗口「添加标记」下方，与标记同排对齐。连接后读取**当前目标影片库**的「我的标签」列表（含零关联标签），可多选。
- **可直接输入新标签名**：下拉框内置输入框——输入新标签名（如片单标题）点击「添加」或回车，即生成可移除的「新建」条目；保存时由桌面端在影片库标签目录中自动创建。JavDB 用户分享的片单无需先去主程序手动建标签。
- **保存后随时调出**：影片保存入库后在「我的标签」分区点击标签名，即可用与主库浏览相同的卡片界面查看完整清单（分页、搜索、点开详情等全套交互）；标签卡片上的「管理影片」按钮可搜索并勾选/取消关联。
- **全部保存入口均携带标签**：列表勾选后的统一保存、详情页免弹窗直接保存均应用该库记住的标签选择；标签偏好按影片库分别记忆。
- **逐批确认，不假报成功**：桌面端在影片事务内写入 `metadata_to_label` 并逐部回读确认，漏写回滚整批；接收端未确认标签写入时不会显示成功。已有标签被删除时仍会拒绝整批，避免陈旧选择误建。
- **向后兼容**：筛选器「标记」（按 ID 写入 `metadata_to_tagstamp`）功能与校验完全不变，标记与标签可同时使用；旧版插件行为不变。旧桌面端（labelImportVersion < 3）会禁用标签选择并提示更新配套 EXE。
- 导出 JSON 同步包含已选标签。
