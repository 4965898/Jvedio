# Jvedio 6.0.0.3（Jvedio30.4）/ Connector 0.3.1

本版修复 **JavDB 列表卡片“＋Jvedio”按钮不显示**：JavDB 2026 年 11 月改版把列表标题改为单行省略号，按钮被裁剪而“在页面里却看不见”；按钮改挂到卡片日期旁。同时把 JavDB 官方镜像域名 javdb570–575 纳入自动注入范围。桌面端功能无变化。

## 问题与修复

- **现象**：JavDB 列表卡片番号旁的“＋Jvedio”按钮不再显示；番号提取与保存功能正常。
- **根因**：按钮其实一直挂载在页面里——用户提供的真实页面样本中 40 张卡片全部带有完整按钮节点与 shadow DOM。JavDB 新版 CSS 把 `.video-title`（标题）改为 `white-space:nowrap;overflow:hidden;text-overflow:ellipsis` 单行省略号，而按钮原来追加在标题文本行尾，标题占满一行后被 `overflow:hidden` 裁出可视区。旧版标题多行换行、行尾按钮可见，故此前未暴露。本次改版 DOM 结构未变，纯 CSS 变化。
- **修复**：按钮挂载点改为卡片日期旁（`.meta` 优先，无日期的旧版卡片回退标题行）；番号提取、勾选交互与保存链路零改动。第三方脚本包装番号（如“已观看”类脚本的 `<savdiv>` 自定义元素）不影响提取。
- **镜像域名**：JavDB 官方镜像域名按编号轮换（旧域名失效后启用新编号，javdb457、v90f 等已停放），本版把 javdb570–575 整批纳入自动注入；超出本版清单的新域名仍需更新插件，轮换前可点一次工具栏图标经 activeTab 启用当前页。
