# Jvedio 6.0.0.0（Jvedio30.1）/ Connector 0.2.6

本软件自接手维护以来经历了大幅重构与功能增强：翻页渲染与 SQLite 锁修复、资源/图片存在性索引自动维护、启动扫描后台化、翻译系统与任务页、统计仪表盘、我的标签、在线观看跳转、批量导出、NFO 导入导出、备份体系（本地 ZIP + WebDAV/S3 在线备份）、命令面板以及完整的 Jvedio Connector 浏览器剪藏链路等。因此从本版起，版本号定为 **6.0**，后续迭代将从 6.0 开始；本地部署文件名相应进入 `Jvedio30.1.exe`。

本版桌面端行为与 5.4.1.73 完全一致（版本号变更），随版正式发布 **Jvedio Connector 0.2.6**：JavBus、JavDB、JAVLibrary 列表卡片旁的“＋Jvedio”按钮，对同一部影片**第二次点击即取消勾选**——误点不再需要到选择窗口中手动查找；卡片与窗口的选择状态双向同步。选择仍仅限当前页面：同页瀑布流追加保留选择，手动翻页、刷新或关闭窗口清空；保存流程、标记多选、详情页一键保存与图片/预览视频能力不变。

更新插件时覆盖原解压目录，在扩展管理页点击重新加载，确认版本 0.2.6。已有网页可先点工具栏图标激活新卡片按钮，保留已加载瀑布流；也可刷新网页。网站权限仍限三站和已知图床，右键入口使用 contextMenus 权限。

在 Jvedio“选项 → 扫描与导入 → 浏览器剪藏”开启接收，将端口和连接密钥填入插件并连接，选择目标库和所需标记。建议同时更新桌面端与插件；已安装 0.2.4 配套预览 EXE 或 5.4.1.73 正式版的也可只更新插件。密钥不出现在发布包或日志中。

## 验证与范围

本版本号变更未改动桌面源码逻辑：Release 构建（主程序、BusCrawler、DBCrawler、LibraryCrawler）与 DispatcherStress 210 项调度检查通过；完整 ZIP 打包校验（EXE 版本 6.0.0.0、依赖、双架构 SQLite、资源与四类爬虫入口）通过。插件侧 60 项回归通过，含六份完整离线页面样本、三次并行点击同一卡片的取消用例、窗口打开时卡片勾选→取消→恢复与复选框的双向同步；真实 Chrome 至接收端的链路测试沿袭 0.2.5 验证，本版仅改选择交互、不涉及接收端协议。

当前支持本机 SQLite 影片库。列表只保存当前页面已有资料与封面，不主动翻页或逐条读取详情；批量补齐完整详情仍按用户决定暂缓。在线布局、登录验证和脚本改版可能影响抓取；缺失资源会报告结果。插件通过开发者模式安装，尚未上架 Chrome 网上应用店。
