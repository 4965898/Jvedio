# Jvedio 5.4.1.73（Jvedio29.81）/ Connector 0.2.5

本版集中完善浏览器剪藏。JavBus、JavDB、JAVLibrary 列表可以通过卡片旁的“＋Jvedio”挑选零散影片，累计勾选后在小窗口点击“保存所选 X 个番号”统一入库；单部详情页仍点击工具栏图标直接保存。

- 新列表默认不全选。不同卡片累计，重复点击不重复添加，窗口和卡片的勾选互相同步；点卡片本身不会入库或打开窗口。
- 选择限于当前页面和当前这次挑选。瀑布流追加保留本页选择，手动翻页、刷新或关闭窗口清空，重新打开不恢复。影片库、标记偏好及窗口大小位置继续记忆。
- 小窗口默认约 380×560，可拖动标题栏移动、拖动边框缩放，同一来源标签页复用，非全局置顶。图标右键可进入影片库、标记和连接设置。
- “添加标记”位于影片库下方、保存按钮上方，自动下拉读取主程序“筛选器 → 标记”的 AV、套路直播、其他等已有定义并支持多选。使用真正的标记 ID，批量与单部统一添加；与影片同事务保存并逐部回读确认。保留原标记及“新加入”；旧文字标签偏好不猜测迁移，升级后重新选一次标记。
- 适配 [JAVBUS封面大图](https://github.com/kygo233/tkjs) 在 JavDB 隐藏首批 40 部、另行生成后续卡片的布局，读取所有已加载内容并去重；窗口打开后继续同步追加。大批次按接收端最多 500 项及低于 1 MB 拆分。
- 保留原批量选择、搜索、复制/TXT/JSON 导出、详情页主影片识别、封面/预览图/演员图、预览视频，以及 LibraryCrawler 1.4.1。缺少连接配置或保存失败时，详情页打开窗口说明原因，不静默改存其他库。

## 验证与范围

60 项插件回归、66 项隔离桌面检查与 23 项真实 Chrome 至隔离 WPF 接收端链路通过。独立读取 SQLite 验证三站零散选择在统一保存前没有写入影片，保存后全部关联所选标记；验证翻页/刷新/关闭清空、卡片与窗口同步、40→240 瀑布流、详情免弹窗和图片/视频链路。测试使用离线站点页面及公开脚本的纯卡片生成函数，未访问用户登录浏览器或执行其完整网络翻页脚本。

当前支持本机 SQLite 影片库。列表只保存当前页面已有资料与封面，不主动翻页或逐条读取详情；批量补齐完整详情仍按用户决定暂缓。在线布局、登录验证和脚本改版可能影响抓取；缺失资源会报告结果。插件通过开发者模式安装，尚未上架 Chrome 网上应用店。
