# Jvedio 6.0.0.5（Jvedio30.6）/ Connector 0.4.0

本版为功能大版本，桌面端与插件均有更新，**需同时更新**。

## 更新内容（桌面端）

### 新功能

- **定时增量扫描+幂等刮削**：可设间隔（30 分钟～24 小时或关闭）的后台静默扫描；新增影片与缺字段旧影片自动入队补齐，只补空字段、不覆盖已有资料，队列中重复任务自动去重。
- **演员资料自动补齐**：
  - 新增 **JAVDatabase 演员源**：按演员出演影片的番号定位站内资料页，纳入身高/三围/罩杯/生日/鞋码（换算国内码）/罗马字英文名/血型/出身地；生日缺失月份或日期时只写已知部分；多人合演影片按演员名自动消歧；番号 404 自动换下一个关联番号（最多 10 个）；页面直接提供年龄时一并写入。
  - 保留 MinnanoAV 源为备用（该站人机验证较严，可在 Headers 填浏览器 Cookie 尝试）。
  - 串行队列执行、任务间 3 秒、每 10 个长歇 15 秒防风控；触发方式：启动后台批量、影片刮削即时入队、演员界面右键“同步信息”（支持勾选批量与整个库一键入队）。
  - 新设置开关：**强制覆写已有信息**（默认关=只补空字段）、**同时保存头像**（默认开，已有本地头像的演员不覆盖）。
- **JavDB 源网页/API 双模式**：每个源可配“自动（网页优先失败回退 API）/网页/API”与 API Token；API 走 jdforrepam 镜像 App API（需 javdb-cli 登录取 token）。
- **备胎影片源**：新增 AvMoo、Javmenu 插件源（默认不启用），排在 bus/db 之后仅在前置源失败时使用。
- **演员界面**：新增去到顶部/底部悬浮按钮（含 Ctrl+Up/Down）、Ctrl+A 全选本页、右键“同步信息（整个库）”、“全选”菜单项。
- **转换英文名/导出演员列表**：均提供“选中演员/仅本页/整个库”三档；导出支持 CSV/Excel/JSON。

### 优化与修复

- **演员界面全面重构**：多选改为与影片界面一致的整卡高亮框选中；点击卡片任意位置即可勾选（评分星星与按钮除外）；右键菜单在整卡任意位置呼出；信息改为分行标签化展示并显示鞋码；姓名正白加粗；排序按任意演员信息生效（修复错位）并新增鞋码排序；编辑演员后影片数量角标不再清零。
- **英文名质量**：JavDB 演员页随机 ID（如 QE4G）不再误存为罗马字，存量垃圾启动时一次性清理；假名转罗马字补齐片假名（キララ→kirara、アンリ→anri 等）。
- **任务页**：新增演员补齐任务页与人像图标；任务按入队顺序从旧到新显示，状态变化不再乱跳。
- 设置页源行新增模式下拉与 API Token（仅 JavDB 源显示），控件暗色主题修复。

## 更新内容（Connector 0.4.0）

- 列表卡“＋Jvedio”对已入库影片显示**“已入库”深红角标**，有 JavDB 详情码时直达详情页，否则打开搜索页。
- 弹窗影片列表同步显示已入库徽标。
- 后台新增 /v1/owned 批量查询（桌面端 6.0.0.5 提供，旧桌面端自动回退不显示角标）。

## 验证与范围

Release 构建通过（FileVersion 6.0.0.5）；四个新插件 DLL 构建通过；插件冒烟（JavDB API 签名、三新插件契约）与 BrowserClipper 回归通过；扩展回归全过（新增已入库角标、/v1/owned 能力位与旧桌面端回退等用例）；解析器与转换器以真实页面与真名样本离线验证（SSIS-699 全字段、真名罗马字转换表）。

当前支持本机 SQLite 影片库；演员资料源可用性受实际网络环境与站点改版影响；JavDB API 需登录 token，匿名请求会被镜像拒绝（自动模式自动回退网页）。
