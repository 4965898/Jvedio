# Jvedio 5.4.1.70 / Jvedio Connector 0.1.2

本版新增独立 Chrome 剪藏插件，支持 JavBus、JavDB、JAVLibrary。列表页可勾选番号和页面已有封面保存到指定影片库；详情页可剪藏详细资料，记住影片库后点击插件即可保存。

- 接收设置位于“选项 → 扫描与导入 → 浏览器剪藏”，与其他设置统一字体、两列对齐及控件样式，白字、始终展开。
- 封面、预览图、演员图、预览视频分别设置；图片在 Chrome 的当前会话中取得后发送图片字节至本机，不向桌面端传递网站 Cookie。
- 补修 JavBus 详情识别、JAVLibrary 标题、演员图跳过、列表图片遗漏及无本地文件时的图片路径回退。图片保存后更新缓存与索引。
- 已有资料只补空白字段；演员关联使用明确的名称/别名证据。缺少头像来源或下载失败会提示。

下载完整桌面 ZIP 可用于首次安装；独立 EXE 用于升级已有完整安装，请先关闭软件并替换原 `Jvedio.exe`。浏览器插件 ZIP 解压后，在 `chrome://extensions/` 启用开发者模式并加载含 `manifest.json` 的目录；更新插件时覆盖原目录并重新加载。新增图片获取权限需要允许三站及其图床访问。安装后在软件选项中开启接收，将端口和连接密钥填入插件。

验证：26 项插件回归、39 项隔离桌面回归、6 项真实 Chrome 至 WPF 链路、18 项原有回归通过，包含图片/预览视频文件实际写入、图片访问会话与来源验证、库范围及演员关联检查。三语 395 个 key 一致；发布包含应用完整 ZIP、EXE 和 Connector ZIP。

当前支持 SQLite 影片库。按用户决定，逐条读取详情的批量完整资料补齐暂缓；结果页仅保存该页已有字段和图片。演员页未公开头像、网站验证或限速时可能无法取得资源，插件会报告结果。预览视频支持可取得的 MP4/WebM 直链，HLS/DRM 暂不下载。插件尚未上架 Chrome 网上应用店。
